§ 02 · KEY FLOW

关键流程

registry.validate -> verifier.verifyAndConsume -> expiry/hash checks -> registry.execute -> result

测试还暴露了一个设计取舍：packages/pipeline/test/execution/SafeExecutor.test.ts:205 到 packages/pipeline/test/execution/SafeExecutor.test.ts:213 里参数 schema 失败会抛 ACTION_PARAMETERS_INVALID，且测试显示 fixture verifier 仍能消费 grant。这说明生产接入时应该先让 registry.validate 过，再进入远端 consume-token，避免无效参数消耗授权。
