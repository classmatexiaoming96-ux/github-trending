§ 02 · KEY FLOW

关键流程

GateDecision(ALLOW + token) -> consume-token -> VerifiedAuthorization -> SafeExecutor final checks

安全点在两端闭环：authority 端由 packages/pipeline/src/decision/DecionisGate.ts:93 确认 action_hash，执行端由 packages/pipeline/src/execution/AuthorizationVerifier.ts:103 确认 claims.binding.intent_hash。即使 token 被拿到，packages/pipeline/src/execution/SafeExecutor.ts:61 到 packages/pipeline/src/execution/SafeExecutor.ts:68 还会要求 decisionId、dossierId、grantId、intentHash 和 expiry 全部一致。
