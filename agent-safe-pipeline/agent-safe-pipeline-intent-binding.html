§ 02 · KEY FLOW

关键流程

proposal + trusted context -> ExecutionIntent -> AuthorityIntentBinding -> canonical JSON -> sha256:intentHash

流程的关键是 packages/pipeline/src/intent/CanonicalIntentHasher.ts:99 的 bindingOf：它把 camelCase runtime schema 映射成 authority 所需的 snake_case protocol fields。packages/pipeline/src/intent/CanonicalIntentHasher.ts:133 的 canonicalize 会按 key 排序，packages/pipeline/src/intent/CanonicalIntentHasher.ts:144 的 deepFreeze 则让 captured intent 在返回后不可变。
