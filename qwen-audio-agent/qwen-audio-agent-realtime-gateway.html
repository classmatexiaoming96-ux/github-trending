§ 02 · KEY FLOW

关键流程

client connect → active voice ownership → speech_started turn → response context → audio/transcript deltas → playback receipt → task notification confirmed → completed task result → announcement queue → spoken or inline delivery

关键流程的价值在于每一步都有可回收状态：server/src/voice/realtime-gateway.mjs:377 的 response watchdog 处理模型沉默，server/src/voice/realtime-gateway.mjs:490 的 cleanup 删除完成上下文，server/src/voice/realtime-gateway.mjs:720 到 server/src/voice/realtime-gateway.mjs:760 则让用户新一轮语音打断旧播放并进入 thinking。
