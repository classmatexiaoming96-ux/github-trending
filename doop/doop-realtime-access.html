01

访问模型很小

小函数守住大部分边界

Doop 的权限模型集中在一个很短的函数：server/access.ts:9 判断 owner、公开链接或成员访问，server/access.ts:14 检查 publicLinkEnabled，server/access.ts:18 检查 members。简单模型的好处是 REST、WebSocket 和 MCP 都能复用，但这也意味着每个入口都必须确实调用 requireCanvas。

3/**
4 * Canvas access, Figma-style: private by default. The owner always has
5 * access; invited members (canvas_members) always have access; everyone
6 * else gets in only when the owner has turned the share link on
7 * (linkAccess 'edit' — unset means 'none').
8 * Ownerless (pre-auth/legacy) canvases stay open so they can be claimed.
9 *
10 * Every canvas-scoped surface — REST, the WS join, MCP tools — must gate
11 * through this one helper.
12 */
13export function canAccessCanvas(userId: string | undefined, canvas: Canvas): boolean {
14  if (!canvas.ownerId) return true
15  if (!userId) return false
16  if (canvas.ownerId === userId) return true
17  if (canvas.memberIds?.includes(userId)) return true
18  return canvas.linkAccess === 'edit'
19}
