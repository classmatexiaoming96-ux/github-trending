本子页聚焦 sources/ksimback-looper/scripts/looper.py 中三个函数：load_yaml → criteria_by_id → validate_gate → normalize_spec。它们就是 compile 子命令的真正工作面。cmd_compile() 只做 dispatch；本子页引用的所有 path:line 都已对源文件 grep 验证。三个函数的契约是："只要任何一项不合规，抛 LooperError；只要全合规，返回的 dict 一定能被 runner 直接 load 跑"。

▸load_yaml / load_json — 严格区分两种 loader

▸criteria_by_id — 把 verification 数组折叠成 dict

YAML 里 goal.verification 是一个数组，每项有 id / type / check 等字段。criteria_by_id() sources/ksimback-looper/scripts/looper.py:177 用 id 当 key 折叠成 dict，然后再 normalize 各类型——programmatic 要有 check argv + expect ∈ {exit_zero, exit_nonzero, stdout_contains}；judge 要有 rubric；human 要有 prompt。每一条不合规直接抛 LooperError sources/ksimback-looper/scripts/looper.py:60，意味着 schema 不只是 validate，还 强约束输入形状。

 177def criteria_by_id(spec: dict[str, Any]) -> dict[str, dict[str, Any]]:
 178    criteria = spec.get("goal", {}).get("verification", [])
 179    if not isinstance(criteria, list):
 180        raise LooperError("goal.verification must be a list")
 181    result: dict[str, dict[str, Any]] = {}
 182    for item in criteria:
 183        if not isinstance(item, dict):
 184            raise LooperError("Each verification criterion must be an object")
 185        cid = item.get("id")
 186        ctype = item.get("type")
 187        if not isinstance(cid, str) or not cid:
 188            raise LooperError("Each verification criterion needs a non-empty id")
 189        if cid in result:
 190            raise LooperError(f"Duplicate verification criterion id: {cid}")
 191        if ctype not in {"programmatic", "judge", "human"}:
 192            raise LooperError(f"Criterion {cid} has invalid type: {ctype}")
 193        if ctype == "programmatic":
 194            item["check"] = normalize_argv(item.get("check"), f"criterion {cid}.check")
 195            if item.get("expect") not in {"exit_zero", "exit_nonzero", "stdout_contains"}:
 196                raise LooperError(
 197                    f"Criterion {cid}.expect must be exit_zero, exit_nonzero, or stdout_contains"
 198                )
 199            if item.get("expect") == "stdout_contains" and not isinstance(item.get("contains"), str):
 200                raise LooperError(f"Criterion {cid} with stdout_contains needs contains")
 201        elif ctype == "judge" and not isinstance(item.get("rubric"), str):
 202            raise LooperError(f"Criterion {cid} needs a judge rubric")
 203        elif ctype == "human" and not isinstance(item.get("prompt"), str):
 204            raise LooperError(f"Criterion {cid} needs a human prompt")
 205        result[cid] = item
 206    return result

▸validate_gate — 三段交叉引用检查

sources/ksimback-looper/scripts/looper.py:224 的 validate_gate() 是 gate 的真正守门员。它做四件事：(1) verdict_policy ∈ {revise_until_clean, fixed_passes}；(2) max_revisions 是非负整数；(3) 每个 criterion id 必须已注册到 criteria_by_id；(4) 每个 member id 必须在 council 里。revise_until_clean 还强制 verdict_source 必须是 judge 角色或 human sources/ksimback-looper/scripts/looper.py:245-251——这是 reviewer vs judge 分离的核心代码锚点。

 224def validate_gate(
 225    name: str,
 226    gate: dict[str, Any],
 227    criteria: dict[str, dict[str, Any]],
 228    members: dict[str, dict[str, Any]],
 229) -> None:
 230    if not isinstance(gate, dict):
 231        raise LooperError(f"{name} must be an object")
 232    policy = gate.get("verdict_policy")
 233    if policy not in {"revise_until_clean", "fixed_passes"}:
 234        raise LooperError(f"{name}.verdict_policy must be revise_until_clean or fixed_passes")
 235    max_revisions = gate.get("max_revisions", 1)
 236    if not isinstance(max_revisions, int) or max_revisions < 0:
 237        raise LooperError(f"{name}.max_revisions must be a non-negative integer")
 238    for cid in gate.get("criteria", []):
 239        if cid not in criteria:
 240            raise LooperError(f"{name} references unknown criterion: {cid}")
 241    for mid in gate.get("members", []):
 242        if mid not in members:
 243            raise LooperError(f"{name} references unknown council member: {mid}")
 244    if policy == "revise_until_clean":
 245        source = gate.get("verdict_source")
 246        if source == "human":
 247            return
 248        if source not in members:
 249            raise LooperError(f"{name}.verdict_source must be a judge member or human")
 250        if members[source].get("role") != "judge":
 251            raise LooperError(f"{name}.verdict_source must name a judge, not a reviewer")

▸normalize_spec — 100 行 setdefault 总动员

sources/ksimback-looper/scripts/looper.py:254 的 normalize_spec() 是整个文件最长的函数。它开篇就是 if spec.get("version") != 1: raise LooperError("Only loop.yaml version: 1 is supported")，然后逐一对 goal.statement / definition_of_done / context_sources[*] / criteria / host / council / gates / loop_control / execution / observability / workspace / privacy 做规范化。规范化的核心套路是：不变就 raise，可选就用 setdefault 注入默认值。这一双轨制让 Looper 既能拒绝坏输入，又能给常规模板自动补全。

§ 03 · EDGE CASES

边界 / 失败模式

  • argv 必须是 list 而非 string — sources/ksimback-looper/scripts/looper.py:169 的 normalize_argv 把 string 走 shlex.split（Windows 关闭 POSIX），list 全字符串走原样。任何 scalar 立刻 raise。
  • criterion id 重复 — sources/ksimback-looper/scripts/looper.py:189 在循环里检查 if cid in result: raise LooperError(f"Duplicate verification criterion id: {cid}")。
  • 无 judge 但要求 revise_until_clean — sources/ksimback-looper/scripts/looper.py:248 用 members[source].get("role") != "judge" 拒绝 reviewer 当 judge 用。
  • council / gates 引了不存在的 criterion — sources/ksimback-looper/scripts/looper.py:239 一行 if cid not in criteria 早拒绝。
  • execution.mode 不是 3 选 1 — in_session / external_runner / orchestrated 是 enum，不在白名单就 raise sources/ksimback-looper/scripts/looper.py:344。
  • PyYAML 没装却尝试 compile — load_yaml 第一行就在 except ImportError 里 raise sources/ksimback-looper/scripts/looper.py:66-70。
  • loop.resolved.json 不写回 loop.yaml — output 永远新文件，不污染 authoring source sources/ksimback-looper/scripts/looper.py:730。
  • schema 与 Python 校验双轨 — schema 漏掉的 edge case（argv 字符串化）在 normalize_spec 兜底；normalize_spec 不知的类型 schema 兜底。两轨重叠是健壮性来源。
