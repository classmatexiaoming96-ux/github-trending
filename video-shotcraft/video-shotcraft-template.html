§ 03 · EDGE CASES

边界 / 失败模式

  • 如果 transform scale 替代 CSS zoom，3D 放大时文字可能先低分辨率栅格化再被 GPU 放大。
  • 如果 children 不按 page-space 坐标定位，元素飞入无法落进真实页面槽位。
  • 如果跳过静帧验收，PageCam 的 DOF 和透视很容易把可读文字变糊。
