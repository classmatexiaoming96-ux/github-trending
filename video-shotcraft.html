§ 00 · OVERVIEW

它解决什么，凭什么值得拆

video-shotcraft 面向 Claude Code / Codex 这类 coding agent，把产品宣传片拆成可执行技能。README 宣称 106 张 shot recipe cards、161 个 motion previews 和一支生产模板；源码侧真正能支撑这个承诺的是模板工程而不是文案。

主模板把成片注册为 1920×1080、30fps、1085 帧，见 src/Root.tsx:6、src/Root.tsx:9、src/Root.tsx:10、src/Root.tsx:11。这一层让后续所有镜头、字幕和音效都落到同一个帧坐标，避免 Agent 在自然语言计划里漂移。

▸核心数据

架构模式
Remotion template + shot-card library + capture pipeline。
核心抽象
PageCam 将全页截图、页面坐标和 2.5D 运镜绑定。
性能/精度数据
1920x1080、30fps、1085 帧；截图按 2x/4x 纹理策略保锐度。
下游依赖
Remotion、Chromium/Puppeteer、真实页面截图、Mixkit SFX。

▸为什么要真实截图

虽然 capture 脚本位于仓库根的 assets 目录，最终模板消费的是 src/aifl/live/PageCam.tsx:30 的 staticFile 纹理、src/aifl/live/PageCam.tsx:33 的 page-space children，以及 src/aifl/live/SceneFlyIn.tsx:5 读取的 layout 坐标。这个设计把“看起来像产品”的手搓 UI 降级为兜底，把截图和坐标表变成主流程。
