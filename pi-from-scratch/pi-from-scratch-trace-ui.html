▸为什么 trace 页面不会轻易漂移

这套 trace 设计的防漂移点分布在生成端和运行端：scripts/generate-traces.ts:55 用源码文本反查行号，scripts/generate-traces.ts:61 找不到 needle 就直接失败；前端侧 web/app/trace-debugger.ts:26 也用同样的 source helper，web/app/trace-debugger.ts:32 在缺失行时抛错。换句话说，文档数据、源码和调试器三者不是弱绑定，只要核心源码移动，生成链路会提醒维护者重新生成 trace。
