RealReplicaBench 真实副本 Agent Benchmark

RealReplicaBench 不是又一个静态问答集，而是把 Gmail、Shopify、Stripe、Alibaba、Google Trends、文件任务和 CLI mock 都包装成可复现实站副本，用来测长程 Agent 是否能在有状态环境里完成业务闭环。

§ 00 · OVERVIEW

它解决什么，为什么值得拆

这个项目的核心价值在于把 benchmark 从“给模型一段题面”推进到“给 Agent 一个可运行工作场景”。入口脚本在 scripts/run_realreplicabench.py:22 找到仓库根目录，在 scripts/run_realreplicabench.py:34 约定 runs 输出目录，在 scripts/run_realreplicabench.py:35 绑定完整 collection；这三处说明它把任务集、运行产物和批量执行器作为同一个发布单元维护，而不是散落的示例脚本。

真正的执行契约落在 TaskSpec：src/real_replica_bench/cli.py:328、src/real_replica_bench/cli.py:340、src/real_replica_bench/cli.py:358、src/real_replica_bench/cli.py:415、src/real_replica_bench/cli.py:481、src/real_replica_bench/cli.py:494。这些行把 task.toml、runtime_mocks、browser/vision 标签、verifier 超时和输出目录串起来，意味着每个任务不仅有自然语言描述，还有可判定的环境需求与评分入口。对长程 Agent 来说，这比单次 API benchmark 更接近生产故障排查和后台办公自动化。

48def parse_scalar(value: str) -> Any:
49    value = value.strip()
50    # Strip inline comments (` # ...`) outside of quotes. YAML treats `#`
51    # preceded by whitespace as a comment; without this our custom subset
52    # parser silently glued the comment onto the value, breaking numeric coercion.
53    if value and not (value.startswith('"') or value.startswith("'")):
54        hash_idx = value.find(" #")
55        if hash_idx != -1:
56            value = value[:hash_idx].rstrip()
57    if value in {"", "null", "~"}:
58        return None
59    if value in {"true", "True"}:
60        return True
61    if value in {"false", "False"}:
62        return False
63    if value.startswith('"') and value.endswith('"'):
64        return value[1:-1].replace('\\"', '"')
65    if value.startswith("'") and value.endswith("'"):
66        return value[1:-1].replace("''", "'")
67    if value.startswith("[") and value.endswith("]"):
68        inner = value[1:-1].strip()
69        if not inner:
70            return []
71        return [parse_scalar(part.strip()) for part in inner.split(",")]
72    try:
73        return int(value)
74    except ValueError:
75        pass
76    try:
77        return float(value)
78    except ValueError:
79        return value

102                if isinstance(grand_parent.get(key), list):
103                    parent = grand_parent[key]
104                else:

106                    grand_parent[key] = parent
107                if not stack or stack[-1][1] is not parent:
108                    stack.append((indent, parent))
109            item_text = line[2:].strip()

112                parent.append(item)
113                stack.append((indent, item))

117                parent.append(item)
118                stack.append((indent, item))
119            else:

123            stack.pop()

127        if not isinstance(parent, dict):

129        key, value = line.split(":", 1)
130        key = key.strip()
131        value = value.strip()
132        if value:
