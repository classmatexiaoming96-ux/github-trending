§ 00 · Source-level Observatory

agentacct 本地 Agent 工作账本

agentacct 是一个 local-first 的 coding-agent 工作账本：它读取 Codex、Claude Code、Hermes、OpenCode 等本地使用证据，却刻意不保存 prompt、response 或工具参数；再把使用、工作事件、证据链接和受控执行投影到只在本机暴露的 dashboard。

§ 00 · OVERVIEW

它解决什么，凭什么值得拆

113def extract_created_event_id(text: str) -> str | None:
114    """Strict single-created-event shape check shared by every wire adapter.
115
116    Accepts exactly the creation-tool payload shape: a JSON dict with a
117    top-level ``"event"`` dict whose ``event_id`` is a well-formed evt id.
118    Rejects (belt-and-braces — the tool-name allowlist already excludes read
119    tools): list-shaped payloads carrying ``"events"``/``"runs"`` lists,
120    error texts, truncated/torn JSON, outcome-only machine_check payloads,
121    and any non-dict shape.
122    """
123
124    try:
125        payload = json.loads(text)
126    except (json.JSONDecodeError, ValueError):
127        return None
128    if not isinstance(payload, dict):
129        return None
130    event = payload.get("event")
131    if not isinstance(event, dict):
132        return None
133    if any(isinstance(payload.get(key), list) for key in ("events", "runs")):
134        return None
135    event_id = event.get("event_id")
136    if not isinstance(event_id, str) or not EVIDENCED_EVENT_ID_RE.match(event_id):
137        return None
138    return event_id

§ 05 · HIGHLIGHTS

为什么它值得进入工具箱

隐私边界明确
代码多次声明不保存 prompt、response、tool arguments、stdout/stderr；这不是 README 承诺，而是 runtime receipt、schema test 和 projection sanitizer 的共同约束。
证据等级诚实
UsageTruthRow 把 client-reported、provider-reported、unknown 等等级固定下来，避免 dashboard 把估算成本包装成真实账单。
迁移可审计
SQLite migration 使用冻结字面量和 checksum，迁移时逐条执行并检查 transaction，不靠动态 schema 生成。
控制面窄化
dashboard 只控制 agentacct 自己启动的 subprocess，外部 Codex/Claude 都是 observed_only，减少误操作面。
§ 06 · RISKS & GAPS

技术亮点之外，别忽略这些

最大风险是项目很新且表面较大：src/agent_chronicle/api.py:19 到 src/agent_chronicle/api.py:169 的 import 扇入显示它已经聚合大量模块，长期维护需要防止 API 层变成中心泥球。另一个风险是本地日志格式由上游客户端决定，src/agent_chronicle/log_evidence.py:189 也能看到它必须追踪 Codex wire shape 变化。

客户端 wire drift
Codex/Claude/OpenCode 日志格式一变，证据配对和 usage import 都需要测试先行更新。
成本不是账单
本地 token/cost 字段不能代表 provider invoice，产品必须持续展示 confidence。
控制面需要用户理解
owned execution 与 observed-only 的区别如果 UI 没讲清，用户可能误以为它能接管现有 agent 进程。
候选库/legacy 双轨复杂
canonical spike 与 legacy reader 并存期间，读写路径和 cutover 策略会增加维护成本。
