§ 02 · KEY FLOW

关键流程

▸接管流程

Bot stuck → requestHelp(reason) → UI shows request → human take() → Bot actions refused → human release() → Bot may act again

server gateway 也把接管写审计：server/src/computer/gateway.ts:428 记录 help requested，server/src/computer/gateway.ts:440 记录 control taken，server/src/computer/gateway.ts:452 记录 release，server/src/computer/gateway.ts:526 到 server/src/computer/gateway.ts:548 记录 secret request/supply 但不记录值。

这组设计把人类输入分成两种：agent-computer/src/control.ts:200 判断人是否可驾驶整页，agent-computer/src/control.ts:135 则只允许向已请求的字段送入 secret。一个是控制权，一个是一次性凭据通道，混在一起会扩大权限面。
