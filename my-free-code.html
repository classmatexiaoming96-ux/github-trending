§ 00 · OVERVIEW

它解决什么，凭什么值得拆

这个项目的核心不是重新发明一个 Agent，而是把本地编码客户端接到多个免费或低成本模型供应商上。入口在 sources/my-free-code/my_free_code/__init__.py:4 创建 FastAPI app，sources/my-free-code/my_free_code/api/routes.py:17 初始化共享 ProviderRuntime，sources/my-free-code/my_free_code/cli/launchers.py:31 和 sources/my-free-code/my_free_code/cli/launchers.py:32 再把客户端环境变量指向本地代理。

它值得拆的原因在于边界很小但覆盖真实问题：鉴权在 sources/my-free-code/my_free_code/api/routes.py:19，模型别名在 sources/my-free-code/my_free_code/core/router.py:3，上游 provider 目录在 sources/my-free-code/my_free_code/providers/catalog.py:10，协议翻译在 sources/my-free-code/my_free_code/core/anthropic.py:11 与 sources/my-free-code/my_free_code/core/responses.py:1。这些点合在一起，就是一个编码 Agent 网关最小可行内核。
