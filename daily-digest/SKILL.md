# Daily Digest — AI 每日速递

## 概述

Daily Digest 是个人主页上的每日 AI/科技资讯模块。它的单一部署位置是：

`https://classmatexiaoming96-ux.github.io/daily-digest/`

单一源仓库是：

`~/repos/classmatexiaoming96-ux.github.io`（user page repo）

注意：`github-trending` 仓库（旧 site source）下也曾有 daily-digest 文件，
但这些是从未维护的副本，2026-07-01 已删除并改为迁移页。
日报的唯一 source of truth 在 `classmatexiaoming96-ux.github.io` 仓库的 `daily-digest/` 目录。

## 部署结构

```text
user page repo (classmatexiaoming96-ux.github.io)
├── index.html         # 主页 Hero 索引有"📰 每日 AI 速递"卡片
├── daily-digest/      # 日报独立模块 ← 唯一 source of truth
│   ├── index.html     # viewer（iframe + manifest.js）
│   ├── calendar.html  # 日历视图
│   ├── manifest.js    # 归档清单（auto-generated by build.py）
│   ├── 2025-06-17.html
│   ├── 2025-06-18.html
│   ├── 2026-06-30.html
│   └── 2026-07-01.html
└── ...
```

`github-trending/calendar.html` 只保留迁移页，3 秒后跳转到新版日历：

`https://classmatexiaoming96-ux.github.io/daily-digest/calendar.html`

## 工作流

每日 cron 在 user page repo 里运行，不在 `github-trending` 仓库运行。

```text
cron job (每日 08:00 UTC)
└── scripts/daily-digest/build.py
    ├── 抓取 AI/科技资讯源
    ├── 生成 daily-digest/YYYY-MM-DD.html
    ├── 更新 daily-digest/manifest.js
    └── commit + push 到 classmatexiaoming96-ux.github.io main
```

`daily-digest/manifest.js` 是日历和 viewer 的归档索引。它由 `build.py` 维护，不要手工改，除非明确是在修复构建产物。

## "点不进去"排查链路

只排查 user page repo 的 daily-digest，不要回到 `github-trending/data/`。

1. 打开 `https://classmatexiaoming96-ux.github.io/daily-digest/manifest.js`，确认目标日期是否在归档清单里。
2. 确认 `https://classmatexiaoming96-ux.github.io/daily-digest/YYYY-MM-DD.html` 是否返回 200。
3. 在 `daily-digest/calendar.html` 里确认脚本是否正确加载 `manifest.js`。
4. 检查 `assets/calendar.js` 渲染结果，目标日期格子是否有可点击状态。
5. 检查 click handler 是否跳到 `index.html#YYYY-MM-DD` 或对应 viewer 入口。

链路是：`manifest.js` → `calendar.html` 加载 → `assets/calendar.js` 渲染 → 可点击日期状态 → click handler。

## "不会出现在 calendar 上"排查

1. 看 `daily-digest/manifest.js` 有没有这个日期。
2. 看 `daily-digest/YYYY-MM-DD.html` 文件是否存在并能在 Pages 上返回 200。
3. 看 `scripts/daily-digest/build.py` 是否生成了 HTML 但漏写 manifest。
4. 看最新 workflow/cron 是否成功 push 到 `classmatexiaoming96-ux.github.io` main。
5. 如果本地有文件但 Pages 没有，先确认 push 和 GitHub Pages 部署状态。
