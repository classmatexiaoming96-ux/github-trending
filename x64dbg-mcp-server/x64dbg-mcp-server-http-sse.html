Http Sse source deep dive

§ 00 · OVERVIEW

HTTP/SSE 层的最小实现

Transport 层的核心是把 Win32 socket 直接包成 MCP 服务：src/core/mcp_server.zig:179（证据 src/evidence.md:9） 启动线程，src/core/mcp_server.zig:264（证据 src/evidence.md:10） 初始化 socket，src/core/mcp_server.zig:312（证据 src/evidence.md:11） 接收连接，src/core/mcp_server.zig:358（证据 src/evidence.md:12） 解析请求。证据索引见 src/core/mcp_server.zig:439（证据 src/evidence.md:33），它说明 JSON-RPC 分发没有外部框架参与。

▸Transport 角色

它同时支持 Streamable HTTP 与 legacy SSE：src/core/mcp_server.zig:393（证据 src/evidence.md:24） 管 GET，src/core/mcp_server.zig:409（证据 src/evidence.md:25） 管 POST，src/core/mcp_server.zig:499（证据 src/evidence.md:45） 建 SSE，src/core/mcp_server.zig:530（证据 src/evidence.md:46） 处理 SSE message。实现集中，调试方便，但也把协议细节暴露给手写 parser。
