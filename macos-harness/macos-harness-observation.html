▸App 解析先消除歧义

App 匹配在 src/macos_harness/macos.py:375 到 src/macos_harness/macos.py:401，它同时比较 PID、localizedName、bundleIdentifier 和 path。关键是 src/macos_harness/macos.py:393 到 src/macos_harness/macos.py:400：多匹配直接抛错，而不是随便选第一个。这对 Agent 很重要，因为错误点击到同名窗口比失败更危险。

375    def _resolve_app(self, query: str | None) -> tuple[Any, dict[str, Any]]:
376        if not query and self._last_app:
377            query = str(self._last_app["pid"])
378        if not query:
379            raise MacOSError("Specify an app name, bundle ID, path, or PID")
380
381        needle = str(query).casefold()
382        candidates: list[tuple[Any, dict[str, Any]]] = []
383        exact: list[tuple[Any, dict[str, Any]]] = []
384        for app in NSWorkspace.sharedWorkspace().runningApplications():
385            info = self._app_info(app)
386            values = [str(info["pid"]), info["name"], info["bundle_id"], info["path"]]
387            lowered = [str(value).casefold() for value in values if value]
388            if needle in lowered:
389                exact.append((app, info))
390            elif any(needle in value for value in lowered):
391                candidates.append((app, info))
392
393        matches = exact or candidates
394        if not matches:
395            raise MacOSError(f"No running application matches {query!r}")
396        if len(matches) > 1:
397            names = ", ".join(
398                f"{item[1]['name']} ({item[1]['pid']})" for item in matches[:8]
399            )
400            raise MacOSError(f"Application query {query!r} is ambiguous: {names}")
401        return matches[0]

556            if depth > max_depth or len(nodes) >= max_nodes:

关键流程

state(app) → _resolve_app → _application_element → _snapshot_tree → _render_tree see(app) → capture_screenshot → Pillow resize → optional pointer overlay → focus report

这条流程解释了为什么 src/macos_harness/macos.py:642 到 src/macos_harness/macos.py:687 返回的是 app、nodes、text、windows 和 screenshot，而不是单张图片。模型可以先读语义树，再需要时看图；如果 screenshot 失败，src/macos_harness/macos.py:676 到 src/macos_harness/macos.py:684 也会保留错误而不是丢掉 AX 状态。
