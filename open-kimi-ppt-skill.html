§ 00 · OVERVIEW

它解决什么，凭什么值得拆

open-kimi-ppt-skill 的核心不是再写一个 PPTX 生成库，而是把 Agent 友好的 PPTD 中间格式、本地可视化编辑器和官方 Kimi 前端导出器串成一条交付链。入口 CLI 在 lib/editor-server.js:26 和 lib/editor-server.js:82 之间暴露本地静态服务，安装命令在 lib/editor-server.js:64 这类 HTTP 响应边界之外由 CLI 处理，从而把“装 skill”和“开编辑器”分成两个明确动作。

项目最值得关注的抽象是 PPTD。浏览器侧的 lib/editor-lib.js:67 负责从 manifest 解析页面列表，lib/editor-lib.js:111 又把可写路径限制为 .pptd 和 .page，避免编辑器把 Kimi iframe 的保存请求扩展成任意文件写入。这个约束让本地编辑器可以自动保存，但不会把 media 或系统路径暴露给远端编辑内核。

架构模式
npm CLI + packaged skill + localhost editor + browser-side PPTX writer。
核心抽象
PPTD manifest、page YAML、imageMap、Penpal RPC、download verification。
下游依赖
Node 18、File System Access API、Kimi neo-ppt public frontend、agent-browser、PyYAML、Pillow。
风险边界
非官方逆向协议可能变更；导出依赖公开前端；本地写入依赖浏览器授权。

§ 03 · PPTD PARSER

▸路径归一化先把危险输入挡住

lib/editor-lib.js:1 是整个文件系统边界的第一道门。它拒绝空路径、NUL、绝对路径、Windows 盘符和 .. 段，再把可用路径压缩成相对路径。后续 lib/editor-lib.js:40 和 lib/editor-lib.js:111 都基于这个函数做组合，因此路径逃逸不会被遗漏在某个调用点。

2  if (typeof value !== "string") {

▸manifest 解析只抽取 pages 和 title

PPTD manifest 的读取非常克制。lib/editor-lib.js:67 支持 JSON pages，也支持 YAML pages 列表；lib/editor-lib.js:98 只额外抽 title。它没有尝试实现完整 YAML 解释器，而是抽取编辑器载入所需的最小字段。这个取舍降低了 parser 复杂度，但也意味着格式兼容范围要靠测试守住。

lib/editor-lib.js · L67-96JavaScript
67export function extractPagePaths(manifestText) {
68  const trimmed = manifestText.trim();
69  if (!trimmed) throw new Error("PPTD manifest 是空文件");
70
71  if (trimmed.startsWith("{")) {
72    const parsed = JSON.parse(trimmed);
73    if (!Array.isArray(parsed.pages)) throw new Error("PPTD manifest 缺少 pages 数组");
74    return parsed.pages.map((path) => normalizeRelativePath(String(path)));
75  }
76
77  const lines = manifestText.replaceAll("\r\n", "\n").split("\n");
78  const pageHeader = lines.findIndex((line) => /^(\s*)pages\s*:\s*(?:#.*)?$/.test(line));
79  if (pageHeader === -1) throw new Error("PPTD manifest 缺少 pages 列表");
80
81  const headerIndent = lines[pageHeader].match(/^\s*/)[0].length;
82  const pages = [];
83  for (let index = pageHeader + 1; index < lines.length; index += 1) {
84    const line = lines[index];
85    if (!line.trim() || line.trimStart().startsWith("#")) continue;
86    const indent = line.match(/^\s*/)[0].length;
87    if (indent <= headerIndent && !/^\s*-/.test(line)) break;
88    const match = line.match(/^\s*-\s*(.+?)\s*$/);
89    if (!match) break;
90    const path = unquoteYamlScalar(match[1]);
91    if (path) pages.push(normalizeRelativePath(path));
92  }
93
94  if (pages.length === 0) throw new Error("PPTD manifest 的 pages 列表为空");
95  return pages;
96}
