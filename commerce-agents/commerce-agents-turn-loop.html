▸EagerDispatcher 让工具调用提前执行

dispatcher 观察 tool_use block 的 JSON 参数，一旦满足 contract 就提前 dispatch；sources/commerce-agents/commerce-common/commerce_common/turn.py:174、sources/commerce-agents/commerce-common/commerce_common/turn.py:186、sources/commerce-agents/commerce-common/commerce_common/turn.py:199、sources/commerce-agents/commerce-common/commerce_common/turn.py:214、sources/commerce-agents/commerce-common/commerce_common/execution.py:214 说明它既追求低延迟，也保留了失败时返回到普通 round 处理的空间。

 174 class EagerDispatcher:
 175     """Tool execution started mid-stream. When a ``tool_use`` block's buffered JSON
 176     parses at ``content_block_stop``, the call's arguments are final — the loop starts
 177     executing then, while the model writes the rest of the round, so tool time overlaps
 178     generation time. ``collect`` is the post-stream join: started calls are awaited,
 179     anything the stream path missed (unparseable buffer, dispatch off) executes from the
 180     final message's canonical args, and every call runs exactly once. ``cancel`` is the
 181     error and malformed-stream backstop; a started task must not outlive its turn."""
 182 
 183     def __init__(
 184         self, execute: Callable[[str, dict[str, Any]], Awaitable[ToolOutcome]], enabled: bool
 185     ) -> None:
 186         self._execute = execute
 187         self._enabled = enabled
 188         self._tasks: dict[str, asyncio.Future[ToolOutcome]] = {}
 189 
 190     def started(self, tool_use_id: str) -> bool:
 191         return tool_use_id in self._tasks
 192 
 193     def dispatch(self, name: str, tool_use_id: str, args: dict[str, Any] | None) -> bool:
 194         """Start ``name`` on ``args``; False when it did not start (dispatch off, already
 195         started, or no parsed args) and the join executes it later."""
 196         if not self._enabled or args is None or tool_use_id in self._tasks:
 197             return False
 198         self._tasks[tool_use_id] = asyncio.ensure_future(self._execute(name, args))
 199         return True
 200 
 201     def settle(self, tool_use_id: str, outcome: ToolOutcome) -> None:
 202         """Give ``tool_use_id`` its outcome without executing it (a call whose input
 203         never parsed); the join returns it in place. A started call keeps its task."""
 204         if tool_use_id in self._tasks:
 205             return
 206         settled: asyncio.Future[ToolOutcome] = asyncio.get_running_loop().create_future()
 207         settled.set_result(outcome)
 208         self._tasks[tool_use_id] = settled
