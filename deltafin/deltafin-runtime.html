§ 02 · KEY FLOW

关键流程

ids -> LazyEmbed -> forward_pass
for each layer:
  read next layer blobs in background
  apply current layer resident tensors
  run attention + routed MoE
  dematerialize or keep pinned
log profile and return logits

这个流程的关键不是“多一个优化”，而是每一步都有明确退出条件。sources/deltafin/tools/kimi_run.py:122、sources/deltafin/tools/kimi_run.py:1333、sources/deltafin/tools/kimi_run.py:1606、sources/deltafin/tools/kimi_run.py:1685 串起来看，能看到 Deltafin 在慢路径、缓存命中、硬件能力和用户请求之间维持同一套语义。
