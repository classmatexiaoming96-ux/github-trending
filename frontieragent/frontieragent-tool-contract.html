§ 02 · KEY FLOW

关键流程

tool call ├─ localize cwd-internal paths ├─ plan mode gate ├─ assess_with_rules ├─ diff / command preview ├─ user approval or deny └─ journal snapshot before mutation

▸允许之后才记录可变更快照

审批链路不是审计日志的替代品。只有动作被允许后，sources/frontieragent/apodex/observers.py:525 才会创建 journal snapshot；这能把“批准”和“真实写入前状态”绑定起来，而不是只保留一条聊天记录。

这个流程的要点是 fail-closed。sources/frontieragent/apodex/observers.py:492 对 RISK_DENY 直接 skip，sources/frontieragent/apodex/observers.py:502 对用户拒绝的动作停止或重定向，sources/frontieragent/apodex/observers.py:525 在允许后才给 mutating op 做 journal snapshot。
