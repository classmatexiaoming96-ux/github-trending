WizardState 数据模型

WizardState 是整个 align-dev 项目的核心数据类型，定义了前端项目的完整配置选项。它位于 types/wizard.ts，包含 7 个步骤的配置组。

类型定义概览

interface WizardState

定义前端项目的所有配置选项，包括框架、语言、包管理器、UI 库、状态管理、工具链等。

document-generator.ts 分段函数

document-generator.ts 是生成前端开发规范文档的核心模块，通过 13 个分段函数（s1-s13）生成完整的 Markdown 文档。

核心机制：版本状态管理

文件使用模块级变量 _v: VersionMap 存储实时版本，通过 mv() 和 pd() 函数在生成文档时插入版本信息：

// 使用常量避免在模板字符串中转义问题
const B = '`'
const FENCE = B + B + B  // 代码块标记 ```

let _v: VersionMap = {}

// 获取包的实时版本，失败时使用回退版本
const mv = (pkg: string, fb: string): string => _v[pkg] ?? FALLBACK_VERSIONS[pkg] ?? fb

// 格式化为 package.json 依赖条目
const pd = (pkg: string, fb: string): string => `"${pkg}": "^${mv(pkg, fb)}.x"`

主入口函数 generateDocument

export function generateDocument(s: WizardState, v: VersionMap = {}): string {
  // 注入实时版本，使 mv()/pd()/标签辅助函数能获取到最新版本
  _v = { ...FALLBACK_VERSIONS, ...v }

  const sections = [
    s1Overview(s),
    s2TechStack(s),
    s3Directory(s),
    s4Naming(s),
    s5Components(s),
    s6StateManagement(s),
    s7Styles(s),
    s8Toolchain(s),
    s9Testing(s),
    s10DesignTokens(s),
    s11Git(s),
    s12CICD(s),
    s13I18n(s),
  ].filter((sec): sec is string => sec !== null)  // s13I18n 对 i18n='none' 返回 null

  _v = {}  // 生成后重置
  return sections.join('\n\n---\n\n')
}

fetchVersions 实时版本获取

export async function fetchVersions(): Promise<VersionMap> {
  try {
    const res = await fetch('/api/versions', { cache: 'no-store' })
    if (!res.ok) return FALLBACK_VERSIONS
    const data = await res.json() as VersionMap
    // 合并：API 结果优先，回退版本填补空缺
    return { ...FALLBACK_VERSIONS, ...data }
  } catch {
    return FALLBACK_VERSIONS
  }
}

该函数从 Next.js API 路由 /api/versions 获取最新版本，失败时使用 FALLBACK_VERSIONS。

版本合并逻辑

_v = { ...FALLBACK_VERSIONS, ...v }
// 即：FALLBACK_VERSIONS 作为基础，传入的 v（API 结果）覆盖同名键

这确保了：

  • 所有已知包都有合理的回退版本
  • API 返回的实时版本能覆盖回退版本
  • 未在 API 中返回的包仍使用回退版本

关键设计模式

模块级状态

版本状态模块化

使用模块级变量 _v 避免在每个函数间传递版本参数，通过 generateDocument 统一注入，生成后重置。

条件生成

条件化内容生成

各分段函数根据 WizardState 的字段值有条件地返回内容（如 i18n='none' 时跳过国际化章节）。

回退机制

版本回退保护

所有版本查询使用 ?? FALLBACK_VERSIONS[pkg] ?? fb 链式回退，确保文档生成不因版本获取失败而中断。

模板模式

分段函数模板

13 个 s*N 函数各自负责一个文档章节，最后通过数组 filter + join 组合成完整文档。
