§ 00 · Source-level Observatory

qm multiplayer agent harness

QM 不是单个 coding agent，而是一套让 Slack、Web、Cron 和多种 agent runtime 共用的组织级 Agent 工作台。源码里最值得拆的是它怎么把人、scope、harness、sandbox、skills 和凭据串成一个可租约化、可审计的 turn。

§ 00 · OVERVIEW

它解决什么，凭什么值得拆

QM 的 README 把它称为“multiplayer agent harness for work”，源码对应的是一个组织级 agent control plane：Web turn 入口先在 src/api/app-turn.ts:56 刷新身份并解析 actor，随后在 src/api/app-turn.ts:102 通过项目 roster 版本保护共享上下文，最后把 surface、conversation、runtime 和权限信息拼成 orchestrator 输入。

它值得拆的原因不是 stars 数，而是边界足够复杂：src/core/orchestrator.ts:189 创建的 orchestrator 同时接入 memory、skills、credential broker、security posture、attachments 和 delivery；src/runs/worker.ts:22 又把 turn 变成可租约、可心跳、可释放的后台 run。

▸核心数据

架构模式
多 surface → durable run queue → orchestrator → sandbox/harness adapter。
核心抽象
Scope、Conversation、Run lease、Harness、SandboxHandle、SkillResolution。
工程强度
源码超过千个 TS/JS 文件，覆盖 CLI、插件、Web UI、沙箱和核心服务。
下游依赖
Fastify、Postgres、Slack、OpenAI/Codex、Claude/OpenCode、Fly/AWS 沙箱。

▸源码阅读路线

第一条路线看 runtime：src/harness/harness-router.ts:12 决定 harness/model，src/api/app-turn.ts:122 在 Web turn 中执行 provider 和模型可用性检查，src/runs/worker.ts:59 再把排队时间和 attempt 注入 orchestrator。

104  let stopped = false;

109
110  async function loop(): Promise<void> {
111    let claimFailures = 0;
112    while (!stopped) {
113      if (deps.canClaim && !deps.canClaim()) {
114        await sleep(pollMs);
115        continue;
116      }
117      let run: Run | null;
118      try {
119        run = await deps.runs.claim(workerId, deps.leaseTtlMs);
120        claimFailures = 0;
121      } catch (e) {

123        if (claimFailures >= CLAIM_FAIL_CRASH_CONSECUTIVE) throw e;
124        swallow("worker: claim failed (transient, retrying)", e);
125        await sleep(Math.min(pollMs * 2 ** Math.min(claimFailures, 5), 5_000));
126        continue;
127      }
128      if (!run) {
129        await sleep(pollMs);
130        continue;
131      }

135            .releaseLease(run.id, run.leaseToken)
136            .catch((e) => swallow("worker: post-stop claim handback failed", e));
137        break;

141      deps.onClaimed?.();

143        await processRun(deps, run, { background: true });
144      } catch (e) {

146      } finally {

148      }
149    }
150  }

177        }
178      })();

180    },
