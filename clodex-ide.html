§ 00 · OVERVIEW

它解决什么，凭什么值得拆

Clodex 的核心问题定义很清楚：AI 编程任务不是一次回答，而是一段可暂停、可恢复、可审计的工程过程。packages/agent-core/src/services/agent-manager/agent-manager.ts:151 把 AgentManager 做成服务边界，packages/agent-core/src/services/agent-manager/agent-manager.ts:163 维护 active agents，packages/agent-core/src/services/agent-manager/agent-manager.ts:227 明确所有状态写入都流过 state-mutations。

这个项目符合源码拆解条件：它与 coding agent 和 AI developer tooling 直接相关，有隔离运行时、MCP runtime、shell execution、runner security、evidence memory 和 cloud-task 恢复链路。apps/browser/src/backend/agent-host/isolated-agent-turn-runtime.ts:16 与源码证据 packages/mcp-runtime/src/config.ts:130 与源码证据 packages/agent-shell/src/engine/shell-service.ts:207 分别代表三条核心执行路径。
