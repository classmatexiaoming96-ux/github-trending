§ 03 · EDGE CASES

边界 / 失败模式

  • 源码把错误路径显式化，但调用方仍要决定 null、throw 和 retry 的业务语义。
  • CLI adapter 依赖宿主机安装对应命令，测试中通过 stub 覆盖，生产中还需要版本治理。
  • 事件流是同步 emitter，监听器自身不能做阻塞重活。
