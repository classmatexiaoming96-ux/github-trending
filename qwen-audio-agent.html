qwen-audio-agent 实时语音 Agent Runtime

qwen-audio-agent 把 Qwen Audio Realtime 放在前台，把 Codex、Claude、OpenClaw、OpenCode 等后台 Agent 放在 ACP 适配层后面，形成“语音协调 Agent + 后台执行 Agent + 项目 Session”的三层结构。

§ 00 · OVERVIEW

它解决什么，凭什么值得拆

第一层入口不是简单 WebSocket 转发。server/src/voice/realtime-gateway.mjs:86 创建 noServer 网关，server/src/voice/realtime-gateway.mjs:112 到 server/src/voice/realtime-gateway.mjs:126 在 upgrade 阶段同时做路径、Origin 和身份校验，这解释了为什么它能被桌面、Web 和 TUI 共用而不是暴露任意 socket。

语音所有权是这个项目的核心状态机之一。server/src/voice/realtime-gateway.mjs:98 到 server/src/voice/realtime-gateway.mjs:109 对同一 owner 广播 active/busy/available，server/src/voice/realtime-gateway.mjs:279 到 server/src/voice/realtime-gateway.mjs:292 决定 takeover 后输入和输出是否真正生效，避免两个客户端同时抢麦。

响应相关性不是靠“最后一条消息”猜测。server/src/voice/realtime-gateway.mjs:144 到 server/src/voice/realtime-gateway.mjs:158 保存 response candidate、turn correlation、transcript 和 permission 集合，server/src/voice/realtime-gateway.mjs:377 到 server/src/voice/realtime-gateway.mjs:400 还放了 12 秒 watchdog，实时模型不开始回复时会重建前端连接。

前台模型拿到的工具定义集中在 server/src/voice/realtime-provider.mjs:17 到 server/src/voice/realtime-provider.mjs:163，其中 server/src/voice/realtime-provider.mjs:197 到 server/src/voice/realtime-provider.mjs:222 把 Qwen Realtime session 和这些工具绑定，所以语音 Agent 可以委派任务、查询状态、处理权限和读写用户记忆。

从语音轮次到后台执行

CLI runtime 负责把本地网关进程安全拉起。cli/src/runtime.mjs:302 到 cli/src/runtime.mjs:349 在没有健康网关时 spawn server，cli/src/runtime.mjs:351 到 cli/src/runtime.mjs:389 再验证实际 backend 协议、归属和凭据，避免连接到配置不一致的旧进程。

▸语音轮次如何关联响应

User speech → speech_started → turnId/generation → pending audio → Qwen Realtime Qwen response.created → response context → audio.delta/transcript.delta → client playback receipts playback.started confirms task notification; playback.ended releases announcement window.

▸后台任务如何回到前台播报

Realtime function call spawn_thinking → ToolCallHandler validates turn freshness → TaskManager creates lane-limited work → Coordinator runs ACP backend → delegated/completed/permission events stream back to the same voice session.

§ 06 · RISKS & GAPS

技术亮点之外，别忽略这些

这个项目的风险主要来自实时音频、后台 Agent 和权限系统同时运行；任何一层的时序错误都会变成用户能听见的错误确认。

实时队列时序复杂
server/src/voice/realtime-provider.mjs:572 到 server/src/voice/realtime-provider.mjs:620 用 response queue generation 控制并发，逻辑可靠但对维护者理解成本较高。
权限 UX 依赖模型语义判断
server/src/voice/tools/tool-call-handler.mjs:440 到 server/src/voice/tools/tool-call-handler.mjs:531 把自然语言同意映射为权限决定，体验自然但必须防止模型误判。
本地进程复用要求严格
cli/src/runtime.mjs:351 到 cli/src/runtime.mjs:389 检查旧 Gateway 兼容性，说明用户机器上已有进程会造成配置漂移风险。
测试偏协议层
server/test/realtime-gateway.test.mjs:39 到 server/test/realtime-gateway.test.mjs:73 覆盖关键函数，但端到端音频设备和真实 Qwen Realtime 网络抖动仍需要更重的集成测试。
